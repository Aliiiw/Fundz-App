# Fundz App

Fundz App is a mobile app project for viewing stock-market data. This repository currently works as the public showcase/package page for the app: it includes the README, license, and a recorded demo video, while the application source code is not included in this repo.

## Repository Contents

- `fundz.mp4` - local video demo of the app.
- `README.md` - project overview and usage links.
- `LICENSE` - repository license.
